Rare events in multiplicative sequences

A multiplicative identity can persist at every scale and still disappear from a rare-event count. Which relations survive depends on the event, the information retained and the observation clock.

The calculation and what it establishes

Set a=1 and b=(1−|c|)₊. In the limit, U, V and C are independent, with U,V∼Pois(1−b), C∼Pois(b). The margins are U+C and V+C. Their total is U+V+2C.

\mathbb E(A+B)=2,\quad \operatorname{Var}(A+B)=2+2b,\quad \mathbb P(A=B=0)=e^{-2+b}.

The finite law is the k-fold convolution of probabilities 1−(2−b)/k, 2(1−b)/k, b/k at 0,1,2. Its same-grid cluster comparison has total variation at most (2−b)²/k; a continuous-position target is a separate weak limit.

Useful terms

Open a definition when you need it.

Rare event and run start

An occurrence whose probability decreases as the scale grows. A run is a string of equal signs; counting its start avoids counting the same run several times.

Values at primes

The original random choices. The rule F(ab) = F(a)F(b) then determines the other integer values, which are therefore not independent.

Source and cluster

A source is a shared random cause. It may generate several related occurrences; their group is a cluster.

Intensity

The expected number of occurrences in a region. It is neither the observed count in one draw nor, when clusters occur, the expected number of sources.

Poisson law

A count distribution for isolated occurrences, described by its mean. When one source produces several occurrences, a compound Poisson law may be needed.

Observation window

The region and information retained: a total, positions, signs or evolution over time. These observations do not all retain the same information.

Total variation distance (TV)

A number between 0 and 1: the largest probability difference between two models for the same observable event. A value near 0 means that the models are hard to distinguish at that observation level.

Example, simulation and limit

An example displays one draw; a simulation repeats draws; a limiting law describes an asymptotic regime proved under assumptions. Visual agreement does not replace those assumptions.
